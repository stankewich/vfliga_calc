## Примечания

- Задачи с `*` — опциональные (property-based тесты), можно пропустить для быстрого MVP
- Каждая задача ссылается на конкретные требования для трассировки
- Весь код — в одном файле `calc.user.js`
- Property-based тесты проверяют свойства корректности из дизайн-документа
- Checkpoints обеспечивают инкрементальную валидацию
